# SafeStep

## App Name
SafeStep

## App Description
SafeStep is a personal emergency protection application designed to help users send SOS alerts quickly using Shake Detection, Voice Keywords, and Hand Gesture Detection.

## Category
Safety & Emergency

## Version
Version Name: 1.0
Version Code: 1

## Features
- Shake Detection
- Voice Detection
- Hand Gesture Detection
- SOS Alerts
- Location Sharing

## Permissions
- Location
- SMS
- Microphone
- Camera
- Sensors

## Privacy Policy
SafeStep only uses permissions required for emergency protection features. No personal data is sold or shared with third parties.
